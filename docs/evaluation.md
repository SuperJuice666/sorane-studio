# 导入质量评估

评估分为文字、声学边界、读音和设备播放四部分。每份报告记录音频指纹、歌词来源、模型版本、配置和实际执行的检查。

## 文字与结构

将草稿与选定歌词来源逐行对应，检查完整性、顺序、重复次数和句界。分段核对录音的音乐变化与重复结构，显示分词检查独立助词、连续重复词及动词活用。

对照使用相同录音。文字比较可先做 NFKC 归一化并忽略标点、空白；句界仍按来源逐行检查。

## 声学边界

先核对原曲、分轨和预览音频的时间基准，再检查全曲 SOFA、CTC 与上下文候选。疑点包括零或负时长、词序倒退、重叠、长尾及重复段串位。

比较两个候选时，按文字顺序匹配完整词及其边界，报告：

- 匹配文字覆盖率、可比词数量及占比。
- 起音与尾音差异的中位数、P90 和最大值。
- 零时长、倒退、重叠及长尾的数量和具体位置。
- 返修后改善、退化和待核实的范围。

这些指标描述候选差异，实际发声边界通过原曲与人声试听确认。分词或可比词集合变化时，随指标注明覆盖范围。裁剪、拼接及手动修订记录原值和采用依据。

## 读音与播放

逐档核对合成查询、WAV 采样数和词时间，再试听特殊汉字、日式英语、长音和语义停顿。

在 Sorane Player 中检查全曲、逐句、逐段循环，以及拖动、换句、换速和模式切换。记录浏览器、设备、操作步骤及结果；iOS 检查首次播放和添加到主屏后的表现。

## 报告与交付

工具执行、数据校验、声学测量、听音和设备检查分别记录。待核实项目保留位置、问题和下一步，按具体证据选取最多 3–5 个优先试听窗口。

耗时分别统计环境准备、资料核对、模型执行、资源生成与复核。模型和文本 API 用量按实际返回字段记录。
