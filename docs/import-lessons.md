# 导入经验与故障判断

这份文档整理录音导入中常见的文字、时间与播放问题。命令和报告见[执行规范](agent-import.md)，分词规则见[文字提示词](../prompts/lyrics.md)。

## 来源、句界和词界

先比较歌手、发行版本、时长和演唱顺序，再确定歌词。同名作品的现场版、视频版和正式录音可能有增删。AWA 公开歌曲页可提供歌词原始分行；保存原始页面与提取文本，站内搜索按实际可用的登录会话操作。提取结果被压平时回查页面中的换行。

Whisper 转写曾出现重复、漏句、无关署名和片尾套话。可分别转写原曲与新分离的人声，用于定位冲突、核查顺序及覆盖；文字定稿仍与歌词来源逐行核对。

歌词和分句采用版本吻合的 AWA 原始分行；乐段按录音的音乐变化与重复结构划分，已有人工核对结果优先保留。分句来源和结构依据分别记录。

逐行保存 canonicalLines 和 lineSource，在声学处理前核对来源行与练习句的一致性。屏幕折行属于显示布局。录音版本差异或用户指定的改动，保存映射后处理。

显示分词会改变声学输入与高亮粒度。独立助词、连续重复词分别显示，动词活用保留可读单位。朗读停顿通过 narrationBreaks 设置，长读音分组通过 readingParts 辅助阅读；三者各自维护。

重新分句时优先重组已复核的逐词时间。新句界落入原词内部或发现漏词时，围绕该处重新对齐并检查相邻句。

## 按现象选取证据

| 现象               | 核查内容                              | 处理方向                             |
| ------------------ | ------------------------------------- | ------------------------------------ |
| 一段后整体错位     | 漏句、额外重复、录音版本、分轨偏移    | 修正文稿或音源后全曲对齐             |
| 前奏进入首词       | 主唱辅音、原曲、人声、CTC             | 扩大前后文重测，区分乐器与主唱       |
| 词尾拖进间奏       | 末音素、全曲与局部窗口、下句起音      | 检查窗口继承的长尾，结合独立转写重测 |
| 尾音截断或进入下句 | 长音、回声、和声、主唱收音            | 对照原曲与人声确定边界               |
| 零时长或词序倒退   | 读音、音素、重复匹配、窗口边缘        | 修正输入并重新测量，保留各轮结果     |
| 罗马字与演唱有差异 | 特殊汉字、数字、日式英语              | 核对 kana/phonemes 后对齐            |
| 拖动或换句后才错位 | 播放会话、seek、速率映射、currentTime | 复现对应路径，修复播放状态与映射     |

SOFA、局部上下文与 CTC 共享输入，解释一致程度时需同时检查文字和重复段。由错误边界生成的局部窗口可能继承长尾；返修时加入新的证据和上下文。

独立转写通过单调匹配定位宽松句群，扩展上下文后重跑 SOFA / CTC。这曾改善零时长、词序倒退和部分长尾，也增加过某些 CTC 分歧。报告同时保留改善、退化和可比词覆盖。ASR 时间用于选窗口，词时间来自声学测量。

## 边界修订

按实际主唱收音保留长音，并区分回声与下一句起音。重叠裁剪会改变尾音，因此需要结合原曲、人声和上下文确认。每项修订记录原值、新值、依据和相邻词检查结果。

seek 后的错位应在播放会话和映射中定位。全局字幕偏移会同时影响其他播放路径，修改后需覆盖拖动、换速、换句和模式切换。

issues 随问题调查持续更新。模型候选、修订结果和检查报告分别保留，待核实的内容与候选一同交付。

## 读音合成

三档读音分别合成，每档从引擎查询计算词时间。语义组控制短停顿，显示词界用于读音对应。原曲先完成原速标注，再生成变速资源。

歌声与语音引擎的长音标签分别处理。曾出现 e+i / e+e、o+u / o+o 以及组合假名转换差异。先查询歌词文字，核对音素后采用；需要时再查询指定片假名，保存两份查询。WAV 采样时长与查询验证计时，实际读音与自然程度通过试听检查。

## 评价与交付

对照采用同一份录音并核对时间基准，两行歌词共用音频 currentTime。按普通导入水平评价候选，人工精修版作为进一步改善的参考。

报告文字覆盖、可比词数、起尾音分布和少量极端差异。优先提供最多 3–5 个有证据的试听片段。代码执行、数据校验、声学测量、实际试听和设备检查分别记录。

设备检查包括全曲、单句、段落循环，以及拖动、换句、三档速度和模式切换；iOS 还检查首次播放和添加到主屏后的表现。记录实际设备与浏览器，待检查项目明确交接。

指标、对照方法和报告内容见[导入质量评估](evaluation.md)。
