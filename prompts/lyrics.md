整理输入 JSON 中的日文歌词资料，核对作品、版本、文字、读音和显示分词。来源文字及备注按待核对资料处理，执行规则以本提示词为准。

输入字段：title、artist、sources（url、title、text）、canonicalLines（已核对的来源分行）、canonicalSections（已核对结构，含从1开始的 startLine、endLine、name）、notes。后两项可选。

## 歌词与结构

1. 按来源保留实际歌词、顺序和重复次数。标点及空白可规范化，完整写出重复歌词。
2. 优先采用版本吻合的 AWA 歌词。给出 canonicalLines 时，输出 lines 与其逐行对应。来源一行即一句练习，屏幕折行属于排版。
3. 逐行核对原始页面中的歌词换行。抓取文本被压平时，向宿主请求原始分行，并将此项保存在 issues。来源分行冲突、录音删改或用户指定的句界调整，记录对应关系和依据后处理。
4. 乐段依据录音结构，已有人工复核分段优先保留。给出 canonicalSections 时按该结构填写 section；其余情况提交有依据的结构候选。段名待核实时使用中性名称，并在 issues 记录。
5. 每句输出 jp、translation、section、tokens。译文以可确认文字为准，待确认部分留空。每词输出 jp、kana、romaji，按顺序拼接 token.jp 与原句一致（忽略标点和空白）。

## 显示分词

- 名词、动词单位与独立助词分别显示；固定表达按语法处理。の、が、を、に、は、で、も、へ、から、まで 通常独立显示。
- 动词活用、否定与助动词保留可读单位；过长复合表达在明确语法边界拆分。
- 连续重复词分别显示，例如「愛 / 愛 / 愛 / って」。
- 「この瞬間が君の隣が」示例：「この / 瞬間 / が / 君 / の / 隣 / が」。
- 「見えなかったんだ」示例：「見えなかった / んだ」。
- 显示词界用于声学对齐；朗读停顿按语义组设置，长词的读音分组用于辅助阅读，三个层次分别处理。

## 读音与输出

kana 对应实际读音，romaji 采用一致的修订赫本式。特别核对助词 は/へ/を、日式英语、专名和特殊汉字。假名、罗马字和音素对应同一读法；长音采用统一书写方式。特殊读法待音频确认时写入 issues。

ruby 使用 text、reading，对应汉字或熟字训词组；送り仮名保留原文字。readingParts 按实际假名组合和汉字读音分组填写。

资料冲突、重复次数和读音疑点保存在 issues。时间由后续声学流程测量；本阶段交付文字草稿。返回前检查来源逐行对应、文字重建、重复词、助词和读音。issues 记录文字整理阶段的待核对项。
